# CP 30

An interactive, Brilliant-style course for competitive programming in Python, in 30 days. It is built from the book *The 30-Day Python Competitive Programming Roadmap*.

- **A day-by-day plan.** Day 0 to Day 30: learn the idea, type the template, solve the day's real problems, drill recognition.
- **Teach first, then check.** Every lesson explains the idea with a picture and a worked example before it asks anything.
- **Real Python in the browser.** Code steps run your Python with Pyodide and test it.
- **Algorithm labs.** Two pointers, windows, binary search, heaps, BFS, Dijkstra, DP tables, Fenwick trees, KMP and more, step by step.
- **The 15-second recognition gym.** 150 disguised problems with a timer and spaced repetition.
- **Trackers.** Today's plan, problem checklist, mistake journal, re-solve queue and progress table, saved in your browser.

## Run it

```bash
bun install
bun run dev        # http://127.0.0.1:5181
bun run validate   # content rules
bun run build
```

Stack: Vite, React 18, TypeScript, framer-motion. Progress is stored in `localStorage` only.
